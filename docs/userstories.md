# User Stories — Indigenous Crafts

These stories describe the main ways Viewers, Posters and Admins use the site. They are based on `requirements.md`.

## US-01 — Register and log in

As a new visitor, I want to create an account and log in, so that I can see the crafts shared on the site.

- I can register with my email address, and I have to verify it before I can log in.
- I can log in with my email and password and stay logged in the next time I visit.
- I can log out, and I can reset my password if I forget it.
- If I'm not logged in, I only see the landing, register, login and password reset pages.

Related: FR-01, FR-02, FR-03, FR-04

## US-02 — Browse and view crafts

As a Viewer, I want to browse crafts and open the ones I like, so that I can learn about them and their stories.

- I can see a list of published posts.
- When I open a post, I see all its details, including the backstory.
- I can't see other users' drafts.

Related: FR-13, FR-12

## US-03 — Search and filter crafts

As a Viewer, I want to search crafts and filter them by tag or category, so that I can quickly find what I'm interested in.

- I can search posts by keyword.
- I can filter posts by a tag or a category.

Related: FR-14

## US-04 — See where a craft comes from

As a Viewer, I want to see a craft's location on a map, so that I know where it comes from.

- A post's page shows its location on a map.

Related: FR-15

## US-05 — Create and publish a craft post

As a Poster, I want to share a craft with all its details, so that others can learn about it.

- I can start a new post with the "New Craft" button.
- I fill in the title, description, tags, categories, dimensions, colors, tools, backstory and location. Custom text is optional.
- I can preview the post before publishing it.
- I can't publish without a location. Once published, other logged-in users can see the post.

Related: FR-05, FR-06, FR-07, FR-08, FR-16

## US-06 — Save a craft as a draft

As a Poster, I want to save my post as a private draft, so that I can finish it later and check how it will look before I publish.

- I can save an unfinished post as a draft.
- Only I can see my drafts.
- I can come back to a draft, edit it and publish it.

Related: FR-11, FR-12, FR-08

## US-07 — Manage my own posts

As a Poster, I want to see and manage everything I've posted, so that I can keep my posts up to date.

- I can see a list of my posts and drafts.
- I can edit or delete my own posts, but not anyone else's.

Related: FR-09, FR-10

## US-08 — Propose a new tag or category

As a user, I want to suggest a tag or category that doesn't exist yet, so that my craft can be described properly.

- I can propose a new tag or category.
- It stays pending until an admin approves it.

Related: FR-17

## US-09 — Like or favorite a craft

As a Viewer, I want to like or favorite crafts, so that I can show appreciation and find them again later.

- I can like or favorite a post and undo it.

Related: FR-19

## US-10 — Report a post

As a user, I want to report a post that seems wrong or inappropriate, so that an admin can check it.

- Every post has a "Report" button.
- I write what the problem is before sending the report.

Related: FR-20

## US-11 — Handle reports and moderate posts

As an Admin, I want to review reports and act on posts, so that the site stays accurate and respectful.

- I can see the list of reports.
- I can hide, restore, edit or delete any post.

Related: FR-21

## US-12 — Manage tags and categories

As an Admin, I want to manage the official tags and categories, so that posts are organized consistently.

- I can add and edit official tags and categories.
- I can approve or reject tags and categories that users propose.

Related: FR-18, FR-16, FR-17

## US-13 — View site traffic

As an Admin, I want to see basic traffic numbers, so that I know how the site is being used.

- I can see numbers such as visits, new users and new posts.

Related: FR-22
